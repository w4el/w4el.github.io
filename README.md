# w4el.github.io

Source for [w4el.github.io](https://w4el.github.io), the portfolio of Wael Al Mobarak.

Plain HTML and CSS with a few lines of JavaScript for the clock. There is no build step: GitHub Pages serves `index.html` from the `main` branch.

The typeface is Archivo, self-hosted from `assets/` under the SIL Open Font License (see `assets/OFL.txt`).
