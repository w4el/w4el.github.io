# w4el.github.io

Source for [w4el.github.io](https://w4el.github.io), the portfolio of Wael Al Mobarak.

Plain HTML and CSS with a little JavaScript for the London clock, the mobile menu and the timeline. There is no build step: GitHub Pages serves `index.html` from the `main` branch.

The typefaces are Inter, Geist and Geist Mono, self-hosted from `assets/` under the SIL Open Font License (see the `OFL-*.txt` files).
